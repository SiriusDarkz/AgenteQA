# DEF-001 · El campo Apellido del checkout no acepta texto con problem_user

- Casos de prueba: CP-08
- Severidad: Crítica — impide completar la compra, el flujo de negocio principal de la aplicación
- Usuario y datos: problem_user · Sauce Labs Backpack · nombre «Ana», apellido «Pérez», código postal «10101»
- Pasos para reproducir:
  1. Iniciar sesión como `problem_user` / `secret_sauce`.
  2. Pulsar «Add to cart» de Sauce Labs Backpack y abrir el carrito.
  3. Pulsar «Checkout».
  4. Escribir «Ana» en First Name, «Pérez» en Last Name y «10101» en Zip/Postal Code.
  5. Observar el campo Last Name y pulsar «Continue».
- Resultado esperado: el campo Apellido conserva «Pérez» y al continuar se llega al resumen (`/checkout-step-two.html`) con «Item total: $29.99», «Tax: $2.40» y «Total: $32.39».
- Resultado obtenido: el campo Apellido queda vacío después de escribir; la prueba falla en `expect(page.getByTestId('lastName')).toHaveValue('Pérez')` con «Expected string: "Pérez" · Received string: ""». Al pulsar Continue la aplicación muestra «Error: Last Name is required» y sigue en `/checkout-step-one.html`.
